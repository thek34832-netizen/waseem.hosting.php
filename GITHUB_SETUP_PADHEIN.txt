===================================================
DEPLOY KE BAAD YE NAYE STEPS
===================================================

STEP 1: GitHub pe upload
   Sab files (upar di gayi list + pehle ki files jo already GitHub pe hain)
   upload/replace kar dein, commit karen

STEP 2: Railway khud naya build/deploy karega
   1-2 minute wait karen, "Deployments" tab mein "Success" dekhein

STEP 3: Sabse pehli dafa site kholenge to LOGIN PAGE aayega
   - Koi account nahi hai, is liye "Sign up" pe click karen
   - Username + Password bana kar account create karen
   - Turant login ho kar dashboard khul jayega

STEP 4: Purana GitHub connect dobara test karen
   - Chunke ab per-user system hai, GitHub connect bhi dobara karna hoga
   - Dashboard -> GitHub tab -> Connect GitHub -> Authorize
   - Is dafa "ZIP extension missing" wala error NAHI aayega (dono tareeqon se
     fix ho chuka hai)

===================================================
RAILWAY VOLUME (agar pehle set nahi kiya)
===================================================
Agar pichli dafa Railway Volume set nahi kiya tha, ye zaroor kar lein warna
har naye deploy pe users/sites data delete ho sakta hai:
1. Railway dashboard -> Settings -> Volumes -> New Volume
2. Mount path: /data
3. Save
